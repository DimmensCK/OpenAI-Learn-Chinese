# Release notes / 发布记录

## v6.0.1 · 2026-10-24

完善项目展示与文件组织，阅读器仍是 V6，学习内容仍为原快照。

- 首屏突出 Sites 在线入口，首页图也可点击进入网站。
- 中英文主页按八个功能逐节配图，增加 11 张实际网页版截图，其中 9 张为深色界面；手机区改为三张等尺寸图片。
- 根目录只保留开始学习.cmd；GitHub 主页与贡献指南归入 .github，英文说明、许可及发布记录归入 docs。
- 修复迁移后的链接和许可范围，增加根目录布局与启动器字节检查。
- 正文、词汇、阅读器及启动器保持原字节；使用说明仅修正迁移后的许可链接。

Expanded the bilingual feature gallery and made the Sites reader prominent. Added 11 actual hosted-reader screenshots, including nine dark views and a matching three-image phone row. The root now contains only the Windows launcher; project guides, legal notices and GitHub support files are grouped in folders. Links and license scope were corrected, with root-layout and launcher-byte checks added. Reader code and learning payloads remain unchanged; the usage guide only updates its relocated license link.

## v6.0.0 · 2026-10-24

首次 GitHub 发布，打包已存在的离线阅读器 V6；不是将网页版 V6.3 回移植到本地。

- 内容保持 2026-10-21 快照：322 篇中英文正文、325 个词条，9 项来源未取得目录记录。
- 提供中英文 README、下载使用步骤、真实界面截图、贡献指南、问题模板及结构检查。
- 自有阅读器代码与原文、译文及其他第三方内容的许可分开说明。
- 阅读器实现与正文载荷保持发布前源文件内容；此次发布不新增人工审校结论。

First GitHub release of the existing offline V6 reader, not a backport of hosted V6.3. The 2026-10-21 content snapshot is preserved: 322 bilingual articles, 325 terms and 9 unavailable source records. This release adds bilingual project documentation, screenshots, contribution guidance, issue templates and structural validation. Reader-code licensing is separate from content rights. Publication does not add human-review certification.
